# 手动选择 Wi-Fi 通话运营商预设

Wi-Fi 通话配置的 ePDG 区域新增“运营商”条目，显示当前自动识别结果或手动选择的运营商。打开后可输入名称、国家（中文/英文或地区代码）或 MCC/MNC，点击“搜索”筛选。每页最多显示 20 条，点击结果立即替换并保存当前卡的运营商预设，无需再点页面“完成”。“自动识别”恢复原来的自动选择。

目录来自原应用实际使用的预设及 MCC/MNC 资料，现有 3,607 条可选记录；同一 PLMN 的不同预设保留不同标识及名称。两字母地区代码按词匹配，避免 PL 错误匹配所有 apple_* 预设标识。标准模板在结果中标注，不将其表述为运营商已验证的正式配置。

选择使用 PLMN + preset ID 持久化，按原有 ICCID/真实 IMSI 的哈希键绑定当前卡。重新打开、重新读同一张卡及应用重启后继续使用该预设；其他卡保持各自设置。

选择后实际替换连接配置，包括显示名称、配置 MCC/MNC、ePDG、IMS Domain、APN、IP、IKE/ESP 算法、Keepalive、NAI/IMPI/EAP 相关域。使用原生 zl3.i 生成该预设的参数，再显式按所选 PLMN 生成原生函数原先从 SIM 推导的域，并沿用所选 PLMN 的 zi5 传输/ISIM 策略。真实 SIM 的 IMSI、ICCID、认证通道与认证计算不修改，不伪造另一张卡身份。

切换预设时清除原运营商的连接字段覆盖，避免“只换名称但仍连旧 ePDG”。用户此前保存的 IMEI、短信中心列表和当前短信中心选择保留。选择后仍可修改单项参数；单项“重置为内置”恢复的是当前所选运营商的默认内容。原有保存冲突、换卡、连接中禁止修改及存储失败回滚检查保留。

示例：即使实际读取的 IMSI 前缀是 20404，手动选“DITO · 菲律宾 · 51566”后，配置 Domain 为 ims.mnc066.mcc515.3gppnetwork.org，标准 ePDG 为 epdg.epc.mnc066.mcc515.pub.3gppnetwork.org，身份字符串使用原始 IMSI 搭配所选预设域。不会保留原运营商的自动 ePDG 候选。

验证：495 项 JVM 断言，包含搜索、分页、点击立即应用、实际参数与标题同时变化、恢复自动、重新读卡记忆、其他卡隔离、单项重置跟随所选默认、存储失败回滚及不修改真实 SIM 身份。实际 APK 检查 7,250 项原生目录键/模型/反射约束，所有 3,607 个键有效且唯一；另执行现有切卡、简洁编辑器与 DEX 参数类型检查。

没有手机实测。现有 DITO 为 standard_plmn_51566 标准模板，不是经过运营商或设备验证的正式参数；选择后能否注册仍取决于实际 SIM、网络及运营商支持。保留前次切卡类型修复与简洁编辑、多条记录功能，签名证书不变。
