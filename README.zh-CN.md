# 简洁配置编辑与多条记录

配置弹窗仅显示字段名、输入框、“保存”和“重置为内置”。不再展示内置/已保存/预览/说明等重复信息，不再要求“暂存修改”后回上一页再次保存。输入不合法或保存失败时才显示对应错误。

没有自定义值时填入实际内置内容；有保存值时填入已保存内容。点保存立即持久化并应用当前项或当前组，关闭页面后仍保留。点重置立即删除当前项/组的自定义数据，输入框恢复内置内容，不影响其他已保存项。未点保存的输入在关闭弹窗时丢弃。默认不存在的内容保持空输入，不把“自动”“未设置”等说明当成真实配置值保存。

ePDG、短信中心与 IMEI 入口统一打开这种弹窗。ePDG 按顺序保存多条服务器；短信中心保存多条号码并选择当前使用的一条。内置条目与新增条目使用完全相同的输入、编辑、删除及选择控件，没有只读项目或来源标签。删除全部条目后可以保存空列表，重新打开仍为空；重置恢复完整内置列表。显式空短信中心列表不会在发送时悄悄改用已经删除的卡内号码，而是提示先添加短信中心。没有重写 SIM 的卡内数据。

单项保存使用原有每卡配置记录，并保留版本冲突、换卡、正在通话、存储失败检查；不会连带保存其他尚未完成的字段。旧配置记录的现有值继续保留。短信中心列表使用追加的持久化字段，不改变原有字段的索引或旧记录语义。

验证：443 项 JVM 断言，包括真实编辑器 Java 回调配合 Android/Compose 替身、列表删除/重开/重置、选中短信中心、立即保存、冲突及回滚。实际 APK 另检查原生 ePDG/SMSC/IMEI 入口、列表按钮三参数 Compose 回调契约、捕获范围内的空短信中心发送检查，以及 DEX 调用寄存器类型。上一版切卡读回参数 Ldt0 修复保留。签名证书不变。
