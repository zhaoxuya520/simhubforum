# SIMHub 23.1 手机卡槽测试版 fix4

新增原 Wi-Fi 通话区域的“检测当前节点”：读取当前运营商 ePDG 地址，沿用本应用当前网络路径，检测 DNS、UDP 500/4500 与 IKEv2 初始协商。支持取消、重新检测和复制结果。

使用：覆盖安装 → 读取 SIM2 → Wi-Fi 通话区域 → 检测当前节点 → 开始检测。更换节点后重新检测。

结果区分预检通过、部分通道可达、尚未确认。预检通过不等于 SIM 认证、IMS 注册或实际通话成功；完整连接请继续使用原“开启 Wi-Fi 通话”按钮。超时不会直接判定节点不支持。检测采用常见 IKEv2 协商方案，网关拒绝该方案不代表原连接必然失败。
