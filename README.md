# SIMHub 25.5 通话翻译

安装 SIMHub-25.5-signed.apk。服务器部署与配对方法见 SIMHub-translation-relay-25.5.zip 内的 README.md。完成配对后，通话右上角齿轮可以分别开启字幕和同传，并为两项选择不同的目标语言。测试密钥会分别验证两个 Google 模型。字幕支持手动翻阅与回到最新，本次通话中保留最近 80 条历史译文。

本次所有 AI 字幕和语音翻译都经配对服务器调用 Google。配对需要可访问的 HTTPS 中转，以及有对应模型权限与额度的服务器端 Google 密钥。设备配对凭据由服务器签发。已验证应用签名、本地 HTTPS 模拟上游、两种语音采样率和断线恢复。真实 Google 项目、运营商通话及生产服务器尚待联调。
