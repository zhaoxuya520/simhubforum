# SIMHub Android 24.7

在已有会话或新建短信页打开 **RCS**。状态显示 **已连接** 后，点原发送键即可提交一对一 RCS 文本。服务不可用时会保留草稿，关闭开关后可以手动发普通短信。

本版可以连接系统提供的 GSMA TAPI 聊天服务，也可以连接由用户选为默认短信应用并公开兼容接口的服务。SIMHub 会核对访问权限、服务注册号码、当前卡和联系人。更换默认短信应用或撤销授权后，依赖旧服务的会话会停止发送。

连接未成功时，页面会区分未公布聊天接口、服务停用、提供方不受信任、缺少访问权限等情况。其他短信应用的 RCS 注册状态仅反映该应用自己的线路，SIMHub 需要独立核对接口授权。运营商实网投递需用开通服务的 SIM 验证。

**Android 17 安装顺序。** 如果安装 SIMHub 后才装了兼容的默认短信应用，且页面提示“设备未授予 SIMHub 访问 RCS 服务的权限”，可以在该短信应用安装好后，用本页同一签名的 APK 覆盖安装一次 SIMHub，保留原有数据。在 Android 17 模拟器上，这让系统重新授予了短信应用声明的普通 GSMA 访问权限。系统私有接口和签名级权限仍需服务提供方授权。

本机读卡器中的卡可与 Android 活动订阅唯一匹配时，若直连 RCS 服务不可用，且这一会话没有待确认的 RCS 发送，短信页会提供 **用默认短信应用打开草稿**。点击后在该应用里核对所选 SIM 和发送方式，再手动发送。SIMHub 会保留原草稿。外部读卡器中的卡需要兼容该线路的直连 RCS 服务。

**验证情况。** Android 17 模拟器通过了 38 项默认短信应用与 RCS 连接检查。兼容测试服务被选为默认应用后，成功收发文本并返回状态回执。撤销默认角色后，SIMHub 停止使用该会话，原服务收到的新发送请求为零。Android 11 模拟器通过了 290 项 RCS 检查和 625 项覆盖升级回归检查。测试使用模拟线路，一加手机上的运营商实网收发仍待验证。
