## 本次融合

仔细核对用户提供的 SIMCAT 0.0.1（code 157）APK、官方发布校验、Android 调用链和 Go 引擎指令，并以实际方法探针验证相关行为。以 SIMHub 为主，选择三组改进：

- **通话操作绑定当前会话**：旧通知不能误接听、拒接或挂断下一通电话；麦克风授权回调核对授权结果和原来电身份，最终选定通话对象时再次检查。
- **Wi-Fi 通话分支隔离**：同一次拨号出现多个接通响应时，保留已选通话的地址、路由和音频协商，独立结束多余分支；其后续挂断、更新与响应也不能干扰主通话。
- **日志分享脱敏**：分享时隐藏 SIP/tel 身份和明确业务日志中的号码，兼顾折行鉴权内容，保留定位问题所需的域、端口和语音统计。

保留现有浅/深色界面、简洁字段、多条 ePDG/短信中心、运营商搜索和原生切卡路径。相对 23.3，8 个既有类变化，新增 6 个辅助类；资源、原生库及配置/卡片类一致。没有将 SIMCAT 的账号服务、二进制引擎或界面资源并入应用。
