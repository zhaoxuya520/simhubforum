# SIMHub Android：DITO 同卡归属身份恢复修复

这是基于当前 23.1 Android 补丁的增量修复，参考 [SIMHub v29.3](https://github.com/maow318/simhubforum/releases/tag/v29.3) 的 DITO 处理办法。参考仓库未公开实现源码；研究依据为其发布说明及校验过的 iOS 安装包。

- 仅将指定 DITO ICCID 范围（8963662600 开头）的 51566／20404 身份组合识别为 DITO，避免 Wi-Fi 通话预设自动落到 Vodafone。其他卡仍使用原自动识别。
- 实际读到同卡真实 51566 IMSI 时按 ICCID 保存并校验。变成 20404 后，为 Wi-Fi 通话配置与原生认证连接提供同一份临时归属身份副本。实际读卡结果、SMSC、卡片传输和芯片管理保持原样；不写 SIM，不推算 IMSI。
- DITO 配置改用稳定的同卡键，并迁移原 IMSI 键下的设置，保留已有短信中心及自定义配置。手动运营商选择继续生效。
- 保留上一版界面、短信中心保存修复和长期签名。原生切卡、通道、AKA、IMS 工作方法保留。原有身份隐藏也覆盖缓存的归属 IMSI。

## 使用前提

安装后必须先在这张 DITO 卡的实际 IMSI 以 51566 开头时读取一次。以后同卡变为 20404，才有真实的归属身份可恢复。旧版没有这份记录；iOS 应用的数据也不会自动转移到此 Android 应用。

若当前一直只能读到 20404，应用可以识别其 DITO 归属，但无法从中反推出缺失的 51566 IMSI，连接会明确提示。清除应用数据或卸载会移除这份本地记录。飞行模式用于取卡前退网，不能补回缺失的身份。

DITO 预设仍为现有的 51566 标准模板，未升级为运营商确认配置。此次修复身份识别和恢复路径，不代表已完成运营商网络注册实测。

## 验证与安装

586 项主机断言通过，包括 75 项 DITO 恢复、隔离、迁移与隐私断言；原短信中心、配置编辑及状态保护回归通过。实际 APK 的 DEX 检查分析 20 个方法、47 个调用、68 个引用参数，0 个类型错误；19 项 DITO 原生集成检查通过。与上一版短信中心修复 APK 相比，有效载荷仅 classes.dex 改变，界面资源一致。
