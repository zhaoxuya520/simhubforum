# SIMHub 23.1 手机卡槽版 fix2-config2

修复 config1 引入的“无法应用 IKE/ESP 自定义配置”：原 IKE 方法在后段将 p0 复用为 DH 算法列表，上一版错误地把它当成配置对象。现将配置保存在专用局部变量中再过滤算法，避免该本地读取错误。

恢复原“查看 / 修改配置”页面展示、分组、布局和字体。撤掉 config1 的新表单；原 ePDG / SMSC / IMEI 输入框继续使用。IMS、IKE、ESP、Keepalive 按原格式展示，点击后才使用应用原有风格的弹窗修改。

输入先保存在草稿，弹窗确定后点击页面右上角“完成”统一保存；关闭丢弃未保存修改。填写的值优先；清空并保存恢复内置值。既有自定义配置与按卡片保存格式兼容。修改前关闭 Wi-Fi 通话，保存后重新开启。

安装 `SIMHub-23.1-phone-slot-fix2-config2-signed.apk`，沿用之前测试版签名，可覆盖安装，已有 ARA-M 签名授权继续适用。APK 为 Android 安装包。
