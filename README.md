# SIMHub Android 24.6

打开短信会话，在输入框上方开启 **RCS**。显示“已连接”后，用原来的发送键发一对一 RCS 文本。服务不可用时会保留草稿。关闭开关后可以手动发普通短信。

手机需要有已为当前卡开通、并向应用提供 GSMA TAPI 聊天接口的系统服务。仅安装 Google 信息或在其他客户端开通 RCS，无法保证该系统接口可用。应用会核对卡片、注册号码和联系人。短信会话可以显示会话开启期间收到的 RCS 消息以及服务报告的发送状态，近期记录保留在本次应用进程内。

国际拨号修正了德国和英国号码里显式写出的可选国内冠码，例如 `+49 (0)30 …`。早期通话中的 PRACK 和携带 SDP 的 UPDATE 在 TCP 失败后改用 UDP 时，会在原事务期限内重传。实网返回 487 时仍会显示终止结果。具体目的地能否接通须以该卡在运营商网络上的通话为准。
