# SIMHub Android：DITO 与 Wi-Fi 通话参数修复

参考当前最新公开 [SIMHub v29.3](https://github.com/maow318/simhubforum/releases/tag/v29.3) 的标准 IPA，并校验其发布哈希、DITO 配置函数、算法数组、P-CSCF 请求及注册期限。参考仓库只公开安装包，本次没有声称获得其实现源码。

## 本次改动

- 修正上一版仅匹配 `8963662600` 单一卡号批次的漏识别。对交接已确认的 DITO IIN `896366` 与 20404 漫游身份识别为 DITO。真实读到同卡 51566 归属身份后，其他 ICCID 发行范围也可以通过同卡记录恢复。普通 Vodafone 卡仍走原识别。
- 修正读卡完成日志使用替换前本地配置的问题，日志与实际通话配置保持一致。现有连接日志会区分“DITO 已识别”与“缺少归属身份”，不新增界面按钮。
- 将 DITO 通用模板换为独立 `apple_dito_ph` 参考预设：IPv4、IKE AES128/SHA1/SHA1/MODP1024、ESP AES128/SHA1、标准 DITO ePDG/IMS 域、20 秒 NAT 保活、IPsec、1300 字节 UDP 上限、P-CSCF 属性 20/21/16384/16386，以及 7200 秒 REGISTER 注册期限。此预设有参考包依据，尚非运营商确认或实机注册证明。
- 实际读到归属身份后清理旧漫游配置缓存，避免仍沿用旧认证参数；提供给原生认证连接的是不可变的同卡临时身份副本，不改实际 SIM 读取结果。
- 兼容已保存的 `51566|standard_plmn_51566` 选择；保留短信中心与其他自定义数据。原有界面、字体、分组、按钮样式和切卡代码保留；手动配置仍能覆盖内置字段。

## 安装及使用

安装包：`SIMHub-23.1-DITO-v29.3-signed.apk`。沿用之前聊天修复包的长期签名；使用上一修复包的设备直接覆盖安装，以保留数据和已读取的同卡身份。不同签名的更早版本不在覆盖升级保证范围内。

安装后重新读卡。若之前手动选过 Vodafone，运营商选回“自动识别”或 DITO；明确手动选择的其他运营商不会被自动覆盖。

运营商识别与认证所需的归属身份分开处理：即使识别为 DITO，若当前只有 20404 且此应用没有保存过同卡真实 51566 IMSI，仍无法恢复缺失的归属身份。需要在这张卡实际处于 51566 时读取一次。不能从漫游 IMSI 推算；iOS 数据不会自动转移，清除数据或卸载会丢失本地记录。
