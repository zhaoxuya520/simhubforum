# SIMHub 23.1 手机卡槽测试版 fix3

针对同一张 eSTK Max 两颗独立芯片增加互斥启用：启用目标配置前，先完整读取两颗芯片，停用另一颗上的已启用配置并确认，再启用目标。每次停用后及最终完成后重新读取状态；不会只修改界面标记。

停用被拒绝、读取不完整或状态无法确认时停止后续启用；失败后只回读，不重复写入或自动回滚。先停用成功、后启用失败时可能暂时无已启用配置，需要查看状态后重新操作。当前实现适用于 Android 手机卡槽中识别出的 eSTK SE0/SE1 两个不同 EID，不操作手机另一卡槽。

沿用 fix2 的签名，可覆盖安装；原 ARA-M 授权值保持不变：`6F92BF00AF155C4ADA27936451F95ED2F703039C`。

安装后先刷新双芯片状态，再验证“芯片 1 → 芯片 2 → 芯片 1”。若旧状态两颗都启用，可先停用目标配置，再重新启用，让新流程完成互斥切换。操作期间等待刷新完成。
